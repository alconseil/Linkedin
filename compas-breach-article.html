Ce qui s'est passéWhat Happened

Le ministère de l'Éducation nationale gère les affectations des enseignants stagiaires via une plateforme RH interne : COMPAS. Le soir du 19 mars, le COSSIM (centre opérationnel de sécurité des SI du ministère) a détecté une activité anormale. L'attaquant avait déjà quatre jours d'accès libre derrière lui. France's Ministry of Education manages teacher placements through an internal HR platform called COMPAS. On the evening of March 19, the ministry's security operations center (COSSIM) detected anomalous activity. By then, the attacker had already been inside for four days.

Cause racine — Le problème des comptes externes oubliésRoot Cause — The Forgotten External Account Problem

L'attaque n'a requis ni zero-day, ni kit d'exploitation, ni outil avancé. L'attaquant s'est simplement connecté. C'est le type de brèche le plus dangereux : il est indiscernable d'un usage légitime. The attack required no zero-day, no exploit kit, no advanced tooling. The attacker simply logged in. That's the most dangerous kind of breach — it looks identical to legitimate use from every monitoring system's perspective.

Playbook d'audit — Trouvez vos comptes COMPAS avant les attaquantsAudit Playbook — Find Your COMPAS Accounts Before Attackers Do

Chaque grande organisation dispose de comptes créés pour des prestataires, tuteurs ou auditeurs qui n'ont jamais été désactivés. Voici comment les identifier aujourd'hui avec les outils déjà en place. Every large organization has them: accounts created for contractors, tutors, auditors, or seasonal staff that were never disabled. Here's how to surface them today using tools you already have.

PowerShell Entra ID — Comptes inactifs depuis 90+ joursEntra ID — Inactive accounts (no sign-in for 90+ days)
# Requires Microsoft.Graph module
$cutoff = (Get-Date).AddDays(-90)

Get-MgUser -All -Property DisplayName,UserPrincipalName,SignInActivity,AccountEnabled |
  Where-Object {
    $_.AccountEnabled -eq $true -and (
      $_.SignInActivity.LastSignInDateTime -lt $cutoff -or
      $_.SignInActivity.LastSignInDateTime -eq $null
    )
  } |
  Select-Object DisplayName, UserPrincipalName,
    @{N='LastSignIn'; E={ $_.SignInActivity.LastSignInDateTime }},
    @{N='NeverLoggedIn'; E={ $_.SignInActivity.LastSignInDateTime -eq $null }} |
  Sort-Object LastSignIn |
  Export-Csv "entra_inactive_accounts.csv" -NoTypeInformation -Encoding UTF8
PowerShell Active Directory — Comptes dormants activés (on-premises)Active Directory — Dormant enabled accounts (on-premises)
# lastLogonTimestamp répliqué toutes les 14 jours — plus fiable que LastLogonDate
$cutoff = (Get-Date).AddDays(-90).ToFileTime()

Get-ADUser -Filter { Enabled -eq $true } `
  -Properties lastLogonTimestamp, Description, WhenCreated |
  Where-Object {
    $_.lastLogonTimestamp -lt $cutoff -or
    $_.lastLogonTimestamp -eq $null
  } |
  Select-Object Name, SamAccountName, Description, WhenCreated,
    @{N='LastLogon'; E={ [DateTime]::FromFileTime($_.lastLogonTimestamp) }} |
  Export-Csv "ad_dormant_accounts.csv" -NoTypeInformation -Encoding UTF8
KQL Sentinel — Connexions réussies hors pays autorisésSentinel — Successful sign-ins from unexpected countries
let AllowedCountries = dynamic(["FR", "BE", "CH", "LU"]);

SigninLogs
| where TimeGenerated > ago(30d)
| where ResultType == 0           // successful only
| where Location !in (AllowedCountries)
| project
    TimeGenerated, UserPrincipalName, AppDisplayName,
    Location, IPAddress, RiskLevelDuringSignIn,
    ConditionalAccessStatus
| order by TimeGenerated desc
KQL Sentinel — Impossible Travel (même utilisateur, 2 pays en moins de 2h)Sentinel — Impossible Travel (same user, 2 countries within 2 hours)
SigninLogs
| where TimeGenerated > ago(7d) and ResultType == 0
| project TimeGenerated, UserPrincipalName, Location, IPAddress
| join kind=inner (
    SigninLogs | where TimeGenerated > ago(7d) and ResultType == 0
    | project T2=TimeGenerated, UserPrincipalName, L2=Location, IP2=IPAddress
  ) on UserPrincipalName
| where abs(datetime_diff('minute', TimeGenerated, T2)) < 120
  and Location != L2 and IPAddress != IP2
| project UserPrincipalName, TimeGenerated, Location, IPAddress, T2, L2, IP2
| order by TimeGenerated desc
KQL Sentinel — Volume de requêtes anormal (bulk read)Sentinel — Bulk read anomaly detection
// Calibrer le seuil selon le baseline normal de l'application
SigninLogs
| where TimeGenerated > ago(30d) and ResultType == 0
| summarize
    SessionCount = count(),
    UniqueIPs    = dcount(IPAddress),
    Countries    = make_set(Location)
    by UserPrincipalName, AppDisplayName, bin(TimeGenerated, 1d)
| where SessionCount > 50
| order by SessionCount desc
⚠ Gotcha ADAD Gotcha LastLogonDate en AD se réplique seulement toutes les 14 jours entre les contrôleurs de domaine. Toujours utiliser lastLogonTimestamp converti depuis FileTime. Pour les comptes hybrides, croiser avec les Entra ID Sign-in Logs — la source de vérité est toujours le cloud. LastLogonDate in AD replicates only every 14 days across domain controllers. Always use lastLogonTimestamp converted from FileTime. For hybrid accounts, cross-reference with Entra ID Sign-in Logs — the ground truth is always the cloud.

ConclusionBottom Line

La brèche COMPAS n'est pas une attaque sophistiquée par un acteur étatique. C'est la conséquence prévisible de comptes externes non gérés sans aucun contrôle compensatoire. La leçon se généralise à toute organisation qui accorde des accès à des prestataires, partenaires ou personnels saisonniers. The COMPAS breach is not a sophisticated nation-state attack. It is a textbook consequence of unmanaged external accounts with no compensating controls. The lesson generalises to every organization that grants access to contractors, partners, or seasonal staff.

✅ 3 actions pour lundi matin3 Actions for Monday Morning 1. Extraire le rapport des comptes dormants Entra ID / AD avec les scripts ci-dessus. Tout compte externe inactif depuis 90+ jours est à désactiver immédiatement.
2. Auditer les Conditional Access policies. Toute application exposée sur internet doit exiger le MFA pour les identités externes — sans exception.
3. Activer Entra ID Protection. Une connexion à risque moyen doit réveiller quelqu'un dans l'heure, pas quatre jours plus tard. 1. Pull your dormant account report (Entra ID + AD) using the scripts above. Any external account inactive for 90+ days is a candidate for immediate disabling.
2. Audit your Conditional Access policies. Every internet-facing application must require MFA for external identities — no exceptions.
3. Enable Entra ID Protection. A medium-risk sign-in should wake someone up within the hour — not four days later.

L'attaquant dans ce cas n'était pas particulièrement habile — il était simplement patient. Patient au point de rester dans le système pendant quatre jours sans qu'aucune alerte ne se déclenche. L'écart entre des contrôles capables et des contrôles déployés, c'est là que vivent les brèches. The attacker in this case was not particularly skilled — they were simply patient. Patient enough to sit inside a system for four days while no alert fired. The gap between capable controls and deployed controls is where breaches live.

Quatre jours de dwell time. Un seul compte obsolète. 243 000 personnes qui naviguent dans les conséquences pendant des années. Four days of dwell time. One stale account. 243,000 people navigating the downstream consequences for years.
