// Platform verdicts

Four platforms. One constrained choice.

The article covers all four platforms in depth — architecture, TCO, identity, profiles, printing, Teams, DRP, and endpoint management. Here's the field verdict for each.

AWS WorkSpaces
Chosen due to a multi-million AWS financial commitment. Technical gaps compensated by custom tooling. Teams VDI2 offloading now GA — we participated in the TAP.
Citrix DaaS
The most mature platform on printing (CUP), profiles (CPM), and USB redirection (HDX). High TCO justified at scale. Roadmap post-CSG acquisition to monitor.
Azure Virtual Desktop
Best overall value for Microsoft-centric organizations. Native Intune, Entra ID SSO, FSLogix included, Teams offloading, Universal Print. Best platform trajectory at 2026 horizon.
Windows 365
Maximum operational simplicity. Fixed cost, Intune as single control plane, transparent Exchange/OneDrive migration. Perfect for branch agent profiles.

We participated in the TAP. The architecture is sound — but Zscaler CDN bypass, version drift, and thin client hardware floor are still open questions at 8,000 users.
⚡
DRP Registration Code — the Lambda solution
In a WorkSpaces DRP failover, the Registration Code changes. We built a Lambda + DynamoDB + Entra ID JWT authorizer to eliminate 4,000 helpdesk calls.
📁
CPM profile migration — cold extraction
Roaming profiles on file server: no VHDx to mount, direct SMB access. NTUSER.DAT cold hive loading. All Known Folders → OneDrive, zero in FSLogix.
🗂️
60 TB PST pipeline — Purview Import
Aspose.Email per-folder item comparison, macro signing on-the-fly with enterprise code signing cert, 15-day read-only window, corrupted PST quarantine + remediation.
🏗️
Azure migration backend — full architecture
SQL + Automation + Key Vault + Blob + Log Analytics + Power BI. Least-privilege App Reg per service. WinForms Purview GUI. KQL correlation queries.
🔒
CIS XML parser → GPO generation
PowerShell XML parser extracting CIS benchmark recommendations and injecting them into GPOs by product (Windows / Office / Edge / Chrome) with loopback on VDI OU.
🖨️
Print architecture — dedicated network
Print servers on AWS VMs, local branch printers, dedicated print network separate from VDI user traffic. No session quality impact. Migration path to Universal Print.

"WorkSpaces got Teams VDI2/Slimcore before AVD and Citrix finish migrating away from legacy WebRTC. The platform race is more open than the benchmarks suggest."
